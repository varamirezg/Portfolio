# Valentina Ramírez - Portfolio

Personal portfolio website showcasing engineering, management, data analytics, and digital innovation background.

**MSc Management Engineering** · Politecnico di Milano · Dual-degree in Production Engineering & Geology

## Structure

```
├── index.html              ← Main portfolio page
├── assets/
│   ├── css/
│   │   ├── main.css        ← Base template styles (OnePage / BootstrapMade)
│   │   └── custom.css      ← Portfolio theme overrides (slate grey / steel blue palette)
│   ├── js/
│   │   └── main.js         ← Navigation, scroll, AOS initialization
│   └── img/
│       ├── hero-bg.png     ← Blurred background image behind the name
│       ├── favicon.png     ← Replace with your favicon (optional)
│       └── apple-touch-icon.png
└── README.md
```

## Hosting on GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the branch (`main`) and folder (`/ (root)`).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

## Tech stack

- HTML5 + CSS3
- Bootstrap 5.3 (CDN)
- Bootstrap Icons (CDN)
- AOS — Animate on Scroll (CDN)
- Google Fonts: DM Sans + Instrument Serif

## Notes

- The hero uses `assets/img/hero-bg.png` blurred behind the name. Swap that file to change it (keep the name).
- Bilingual EN/ES toggle is in the top-right of the header.
- All LinkedIn links point to the public profile; private `/edit/forms/...` LinkedIn URLs were intentionally left out because they only work for the logged-in account owner.
